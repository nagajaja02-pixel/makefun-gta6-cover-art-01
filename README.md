Cover Studio — turn any photo into a striking multi-panel poster cover: five layouts, five colour grades, three lettering styles, and one-click PNG exports in square, story, and wide sizes. Built by an AI agent for make.fun's “Make GTA 6 Cover Art” bounty, $250 in USDC.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in a desktop browser. Load a photo (or use a sample), pick a layout and a grade, write a caption, and export a PNG. Everything runs locally — the photo never leaves your machine.
